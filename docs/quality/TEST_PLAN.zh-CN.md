# 制造运营智能——测试计划

状态：**RC1 工程测试计划**（2026-09-20）。英文对照：[TEST_PLAN.md](TEST_PLAN.md)。

本计划定义本地合成数据 MVP 的工程证据，不批准 PRD、数据契约、KPI 定义或 BA-01–BA-08 中的暂定制造业务语义。

## 范围与发布门槛

必需证据涵盖四域 CSV/XLSX 摄取、验证和标准化、SQLite 活动批次持久化、确定性分析和异常、五个 Streamlit 页面、Excel/PDF 报告，以及可选 AI 摘要和离线后备。

发布复验要求所有定向回归测试、`ruff check .` 和 `pytest -q` 通过。UAT 还需要单独、带日期的产品负责人 BA-01–BA-08 决议及性能工作负载/目标；任何测试结果均不能替代这些决策。

## 需求到测试追踪

| F04 持久化 | `tests/data/test_repository.py`、`tests/test_application_service.py` | 重启及保留此前活动批次 | 仓储纵深防御加固单独跟踪 |
| F05 KPI 计算 | `tests/test_kpi.py`、`tests/test_application_service.py` | 手工计算正常、边界、空集和零分母示例 | BA-01–BA-05 决定业务验收 |
| F06 异常 | `tests/test_anomalies.py`、`tests/test_dashboard.py` | 审查规则/来源证据及严格阈值边界 | BA-04 决定可接受的阈值/严重度 |

## 测试数据与确定性夹具

| 夹具类别 | 覆盖内容 |
|---|---|
| 干净合成批次 | 90 天、3 条产线、2 个班次、20 个产品、40 个物料；CSV 和 Excel 路径 |
| 验证失败 | 缺失数据域、错误表头/类型、空值、畸形 CSV/XLSX、公式单元格、合并单元格、限制、标准化后重复键及无效关系 |
| KPI 夹具 | 加权聚合、产线/班次/产品/日期筛选、空选择、零分母、零产出、超过 100% 的达成率、库存时点/结转/部分覆盖 |
| 异常夹具 | 触发/不触发/等值边界、同时命中、未定义比率、缺失库存快照、筛选 |
| 报告夹具 | 共享载荷对账、完整异常列表、PDF 20 行披露、过期载荷/摘要、长筛选分页、渲染器隔离、类似公式的来源文本 |
| AI 夹具 | 禁用/缺少密钥/失败/畸形/不受支持声明的后备，以及有效的模拟草稿 |

## 命令与记录

在 Python 3.12 的仓库根目录运行：

```sh
.venv/bin/ruff check .
.venv/bin/pytest -q
```

发布复验还应先运行受影响模块，从干净合成批次生成报告，并将展示值与服务载荷对账。记录 Python 版本、提交哈希、命令输出、通过/失败/跳过/警告计数及任何环境警告，不得隐藏。

## UAT 交接条件

UAT 前，除附上本技术证据外，还应在测试套件外记录：

1. BA-01 至 BA-08 的具名产品负责人决策和日期。
2. BA-07 的获批工作负载、硬件边界及性能目标。
3. 不可变发布标识：包版本 `1.0.0rc1`，并在复验提交上创建 Git 标签 `v1.0.0-rc.1`。
4. UAT 结果记录：执行场景、预期结果、实际结果及签收/缺陷。

在第 1、2 和 4 项存在前，本计划仅支持工程复验，不代表业务 UAT 验收。
