# Manufacturing Operations Intelligence（制造运营智能分析）——验收标准

状态：**工程验收标准已起草；产品负责人验收待定**（2026-09-17）。英文对应文档：[ACCEPTANCE_CRITERIA.md](ACCEPTANCE_CRITERIA.md)。本文规定作品集 MVP 的可观察检查项；不批准暂定的制造业务口径，也不表示客户交付已验收。

## 工程验收检查

| ID | 必须观察到的结果 | 验证方法 |
| --- | --- | --- |
| AC-01 | 本地启动只监听 `127.0.0.1`；支持的启动命令与 Streamlit 配置一致。 | 执行文档命令并检查监听套接字。 |
| AC-02 | 完整四领域 Excel 工作簿或四个已指定领域的 CSV 文件，要么整体接受，要么拒绝并给出数据集、行、字段、原因和严重级别；无效行不得静默消失。 | 有效、混合无效、稀疏、密集及高压缩文件样例。 |
| AC-03 | 被拒输入保留原活跃批次；已接受的替换在重启后可读。持久化的计划、实绩、质量键完全匹配；内容指纹不匹配时须在筛选分析前显示失败。 | 临时 SQLite 集成测试，包括主动注入孤儿记录和篡改。 |
| AC-04 | 每个受支持 KPI 的手工计算正常、边界、缺失和零分母样例符合 [KPI 定义](../data/KPI_DEFINITIONS.zh-CN.md)。缺少生命周期证据时，“已完成订单数”和“计划遵守率”继续标为不可用。 | 确定性 KPI 测试及仪表盘/报告检查。测试通过只验证*已记录的候选公式*，不等于业务批准。 |
| AC-05 | 已配置异常规则确定性地产生类型、严重级别、实体、观测值、阈值、时间范围及解释；严格比较边界不触发，跳过的检查可见。 | 触发、不触发、边界和多异常测试。 |
| AC-06 | 五个仪表盘区域呈现同一选定批次和筛选条件，显示空状态/不可用状态；Streamlit 代码不计算 KPI。 | UI 冒烟测试与源代码审查。 |
| AC-07 | Excel 与 PDF 使用同一分析载荷，展示的 KPI 值与计算引擎一致。长而有效的筛选列表可在 PDF 中分页；一种格式渲染失败时另一种仍可下载。 | 临时文件报告测试、长筛选 PDF 测试及强制渲染失败测试。 |
| AC-08 | 离线或 AI 请求失败时，核心应用继续运行并提供确定性摘要。被接受的 AI 输出只能选择已标识的计算事实；模型给出的数字文本、原因或完工断言不得进入最终叙述；局限说明始终由程序确定。 | 模拟提供方测试，包含不支持的事实和虚假断言；单元测试不访问真实 API。 |
| AC-09 | 在文档所述环境中，`ruff check .` 与 `pytest -v` 通过；校验、KPI、异常、仓库及报告关键行为有专项测试。 | 在 QA 计划记录命令结果和环境，不以全局覆盖率百分比替代。 |
| AC-10 | 作品集素材明确标识为合成数据，不含秘密；说明安装、数据限制及五区域流程。 | 仓库和 README 审查。 |

## 业务验收关口——尚未解决

下列决策须在声称**客户验收**前由具名产品负责人注明日期作出。测试不能代替批准。应在所属权威文档记录决策；若选定口径不同，需同步调整依赖的代码和测试。

| 决策 | 待裁定事项 | 当前实现与文档关系 |
| --- | --- | --- |
| BA-01 | 生产达成率使用总实绩 `actual_qty` 还是合格产出；不同产品的件数能否相加。 | KPI-PA 与 KPI-OL 按草案定义使用总件数；跨产品可比仅作为合成演示假设。 |
| BA-02 | `good_qty` 与 `scrap_qty` 是否代表最终处置；不合格/返工是否计入报废。 | KPI-GY 与 KPI-SR 使用最终合格/报废口径，不是一次通过率或全部不合格率。 |
| BA-03 | 生产时段、计划时间、运行时间、非计划产线分钟、库存快照、安全库存及覆盖不完整的含义。 | 数据契约 C02–C08 与 KPI-TD/KPI-IR 仍属暂定。 |
| BA-04 | 异常阈值、比较边界、生产偏差粒度和严重级别。 | 审查 PRD D06 及已实现的确定性规则规格；阈值不是制造业通用标准。用户在此前异常任务中选择了逐槽绝对偏差，其他业务阈值仍待批准。 |
| BA-05 | “已完成订单数”和“计划遵守率”的处理。 | 当前契约缺少完工/到期证据；除非另行批准契约变更，两项必须继续显示不可用。 |
| BA-06 | 最终导入、持久化、筛选和报告范围，包括 Excel/PDF 与章程 Excel/HTML 的差异，以及库存纳入范围。 | 后续明确的功能任务已授权当前实现；客户交付前须协调章程第 6–10 节与 PRD D01–D05/D08–D10/D15。 |
| BA-07 | 性能目标、工作负载、硬件和计时边界。 | 章程计时目标与 PRD D14 未解决；本文不声称已完成基准测试。 |
| BA-08 | 可选 AI 输出是否属于客户交付，以及要求何种人工复核标识。 | AI 已作为可选功能实现并有离线回退；参见 PRD D07 和 ADR-003。 |

产品负责人应在附日期的决策记录中批准或修订 BA-01–BA-08。在此之前，成果是经过工程验证的**合成数据作品集演示**，不是已获批准的制造运营标准。不得仅为通过验收测试而修改权威业务定义。

## 章程与 PRD 差异对照，供审阅

后续明确的功能请求授权了以下*已实现的演示行为*，但没有改写原章程，也没有批准其中的业务假设。交付前应逐项审阅；只有在产品决策后才同步更新章程和 PRD。

| 主题 | 原章程 | 后续要求与演示 | 待决策事项 |
| --- | --- | --- | --- |
| 输入范围 | 以生产为主的单一模板 | 四领域及 Excel/CSV | 确认四领域批次契约（PRD D01–D03/D10）。 |
| 库存 | 不属于原章程 MVP 工作流 | 库存快照分析和风险视图 | 确认仅物料的截止日口径（D04/D08）。 |
| 持久化 | 优先本地文件，数据库须证明必要性 | SQLite 活跃批次替换 | 确认原子替换且无历史 UI（D05）。 |
| 仪表盘 | 单个仪表盘与少数生产筛选项 | 同一批次上的五个导航区域 | 确认导航范围及库存筛选例外（D08）。 |

| 指标 | 原有五项生产指标 | 八项候选，其中两项仍不可用 | 确认口径及不可用卡片能否满足发布预期（BA-01–BA-05）。 |
| 时间/预算 | 40–60 小时及端到端计时目标 | 扩大后的功能集；无已同意基准 | 重新估算并定义可测工作负载/硬件（D11/D14）。 |
