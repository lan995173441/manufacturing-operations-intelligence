# 安全与可靠性审查——作品集 MVP

日期：2026-09-17；公开演示部署更新：2026-09-20。英文对应：[SECURITY_REVIEW.md](SECURITY_REVIEW.md)。范围：本地、单用户、合成数据 MVP 及其只读公开作品集模式。本审查不认证生产服务或 MES。

## 发现与修改

| 领域 | 结果 |
| --- | --- |
| 上传校验与路径 | Excel/CSV 文件名必须是安全的基础名称并带预期扩展名；上传文件名仅作元数据，从不作为文件系统写入目标。现有路径穿越回归测试拒绝 `../private.csv`。四个规范领域及归一化后关系通过校验才会激活。 |
| 大小与损坏文件 | 数据契约的工作簿/四 CSV 总量 10,000,000 字节限制现于 CSV 解析前检查。UI 在调用 `getvalue()` 前检查上传大小；Streamlit 还把每个文件限制为 10 MiB。XLSX 在只读解析前预检解压量、条目及单元格数；带无效共享字符串引用的合法 ZIP 现返回可见的 `E-PARSE`，不再抛出未捕获异常。被拒输入保留活跃批次。 |
| 临时文件 | 上传和报告产物留在内存中；应用代码不创建上传/报告临时文件。测试数据库和样例使用临时目录。 |
| SQLite 故障 | 原子批次替换及指纹/键校验保持不变。损坏或不兼容数据库显示清晰错误。持久化失败结果现使用固定的安全消息，不再包含可能带本地路径的底层异常文本。 |
| 环境变量与 API 密钥 | `.env.example` 的密钥占位为空；不存在 `.env`。AI 默认关闭，仅按用户请求运行，从进程环境读取密钥；失败时回退且不暴露提供方异常。无效的 `MOI_AI_ENABLED` 现于 UI 显示明确的配置错误。 |
| 浏览器暴露 | 本地启动继续只绑定 `127.0.0.1`。已关闭使用情况遥测，浏览器不显示完整未捕获异常堆栈。公开作品集部署必须设置 `MOI_PUBLIC_DEMO=true`、禁用 AI、使用临时 `/tmp` 数据库，并且不渲染上传控件。它仍无认证且仅使用合成数据。 |
| 凭据与样例数据 | 对 160 个项目素材的模式扫描未发现 API 密钥、云密钥或私钥块；扫描未输出文件内容。`.gitignore` 排除 `.env`、Streamlit secrets、密钥文件和 SQLite 文件。四个仓库样例 CSV 与固定种子合成生成器输出逐字节一致；被忽略的本地活跃数据库指纹也与该样例一致。当前父级 Git 仓库没有追踪本项目文件，因此没有可检查的本项目提交秘密；今后的提交仍需审阅。 |
| 依赖 | 已安装环境通过 `pip check`。隔离运行的 [PyPA pip-audit](https://github.com/pypa/pip-audit) 初次发现旧版 `pip` 和 `pytest` 问题；本地环境已更新至 pip 26.2.1 和 pytest 9.1.1，再次审计报告**未发现已知漏洞**。开发依赖下限现为 pytest 9.0.3，即 [pytest 公告](https://github.com/advisories/GHSA-6w46-j5rx-g56g) 的修复版本。Streamlit 下限提高至 1.54，也排除了[已修复的 Windows 公告](https://github.com/streamlit/streamlit/security/advisories/GHSA-7p48-42j8-8846)涉及的旧版本。未增加应用运行依赖。 |

## 失败行为与边界

- 无效上传返回带源位置的问题；损坏或超限文件不会激活部分批次。数据库故障保留先前已接受的数据，或以可见错误停止依赖的分析。
- 模型超时、失败或响应不受支持时提供确定性的离线摘要。API 凭据不会进入摘要或报告。
- 服务器的 10 MiB 上限按单文件计算；四个选中的 CSV 可在总量校验前占用内存。这对回环地址作品集演示可接受，不适用于公开上传服务。公开演示模式不渲染上传功能。
- 漏洞审计仅覆盖审查时的已安装 Python 环境与公开已知问题。MVP 有意保留灵活版本范围；部署时须重新解析依赖并复审。不要上传客户机密数据。无认证的网络部署仅可使用已记录的只读、合成数据公开演示设置。

## 验证

回归测试覆盖超限 CSV 前置检查、损坏 XLSX 单元格解码、持久化错误消息脱敏和无效环境配置。已确认 Streamlit 配置解析为回环地址、10 MiB 上传、关闭遥测及 `type` 级错误详情。`ruff check .` 与 `pip check` 通过；Python 3.12.2、pytest 9.1.1 环境下 `pytest -q` **138 项通过，用时 49.33 秒**。
