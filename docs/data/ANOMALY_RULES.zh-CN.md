# 异常规则——作品集初始配置

版本：`0.1-draft`。英文对照：[ANOMALY_RULES.md](ANOMALY_RULES.md)。

## 依据与范围

最新用户任务授权五条初始确定性规则，并明确选择**按生产槽位计算绝对生产偏差**。这取代 PRD D06 先前“尚无获准实施的数值阈值”表述，但不意味着这些数值是通用制造标准，也不表示 [KPI 定义](KPI_DEFINITIONS.zh-CN.md)中的所有产品负责人决策均已确认。最终**报废率**不能擅自等同于 PRD 中含义更宽的候选“拒收率”；**总停机时间**是产线分钟数，不是停机率。

生产实体是一个经验证的 `(production_date, line_id, shift_id)` 槽位，沿用 KPI 定义中的已接受批次、关联、日期范围及产线/班次筛选。库存实体是已知物料在所选结束日当天或之前的最新合格快照，不受生产线/班次筛选影响。筛选前先验证完整批次；被拒绝或意外失效的数据不运行规则。当前契约没有事件时间戳，故范围使用本地业务日期。

| 规则类型 | 精确触发条件；边界使用严格比较 | 初始阈值来源 |
| --- | --- | --- |
| `LOW_ATTAINMENT` | 槽位 KPI-PA < 阈值 | 90%，可配置 |
| `HIGH_SCRAP_RATE` | 槽位 KPI-SR > 阈值 | 5%，可配置 |
| `HIGH_DOWNTIME` | 槽位 KPI-TD > 阈值 | 显式配置的产线分钟数；不臆造默认值 |
| `LOW_INVENTORY` | 最新合格快照的 `inventory_qty < safety_stock` | 该物料/快照由源数据提供的安全库存 |
| `HIGH_PRODUCTION_VARIANCE` | 计划量大于零时，槽位 `100 × abs(actual_qty − planned_qty) / planned_qty > 阈值` | 10%，可配置 |

比较使用未舍入值，等于阈值不触发。偏差同时捕捉低于和高于计划的产量，与单向的低达成率规则不同。计划量为零时不构造百分比，跳过该槽位的达成率与偏差检查；实际产量为零时跳过报废率检查。缺少截至日合格快照的物料跳过低库存检查并报告覆盖不完整，其他已观察物料仍可检查。空筛选不生成虚假的零绩效异常。

同一槽位有多条规则触发时，每个规则/实体组合各产生一条异常。异常包含类型、配置严重度、实体、精确观察值与阈值、单位、业务日期范围、解释、比较符、来源引用和规则版本。生产范围为槽位日期；库存范围从观察日期至所选截至日。跳过检查与已评估次数分别输出。运营异常与数据验证错误分开。

## 配置与待决事项

`RuleConfig` 集中管理百分比阈值、必填的停机阈值、启用规则及各规则的严重度。初始严重度均为 `WARNING`；调用方可逐条选择 `INFO`、`WARNING` 或 `CRITICAL`。这里不包含自动升级严重度、原因诊断、UI 规则编辑器或 LLM 判定。规则只消费经验证的 KPI 证据。阈值和默认严重度属于初始演示配置；业务适用性及具体工厂的停机阈值仍待产品负责人确认。
