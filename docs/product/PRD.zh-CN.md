## 1. 目的、受众与需求依据

构建作品集 MVP，展示如何将制造业电子表格转化为可信的运营分析和管理报告。主要用户包括制造业分析师、生产主管、质量与库存人员、运营经理。Upwork 客户和潜在雇主通过完整流程及工程证据评估能力。

本项目仍为面向一个虚构工厂的单用户本地应用，不是生产 MES。本次任务仅授权编写需求文档。

处理本草案前阅读 [AGENTS.md](../../AGENTS.md) V0 及其中文对应文档。项目章程和用户故事已存在；架构、数据契约、KPI 定义、UI 规范、测试计划、验收标准及执行计划尚不存在。缺失不意味着可以编造最终决策。章程保持不变。

## 2. 优先级与产品边界

- **MUST（必须）：** 核心能力 F01–F12：四域、五区域、Excel/CSV 接收、校验、规范化、持久化、确定性 KPI/异常及 Excel/PDF 报告。核心流程不需要 AI API 密钥。依赖未决事项的详细条款仍为草案。
- **SHOULD（应该）——建议，非新增已批准范围：** 可下载指南（S01）及基础键盘/表格可访问性（S02）。
- **COULD（可以）——建议：** 可选 AI 摘要 F13，其发布承诺由 D07 决定。上期对比 C01 是未批准候选项，不是交付承诺。不得仅因列在此处就实施。
- **OUT OF SCOPE（范围外）：** MES 执行、排程、库存出入库或回写、采购、库存估值、多工厂/多用户服务、身份认证、实时集成、任意列映射、预测、统计/机器学习异常模型、可配置规则构建器、聊天机器人/智能体、自动邮件、报告调度、PowerPoint 导出、强制托管和企业基础设施。

## 3. 核心流程与状态

制造业电子表格文件 → 数据校验 → 清洗/转换 → 持久化 → KPI 计算 → 规则异常检测 → 仪表板 → 自动报告 → 可选 AI 管理摘要。

**建议的事务行为（D01/D03/D05）：** 上传完整批次，校验结构和值，仅执行允许的规范化操作，并在提交前重新检查规范化后的关联关系。批次要么整体拒绝并提供诊断，要么整体接受。只有成功持久化后，新数据集才成为当前数据集。导入失败时保留并明确标识原当前数据集，失败输入不会与旧结果混合展示。

报告按需生成，无需人工组装。**建议的摘要行为（D07）：** 初始报告包含确定性摘要。用户可明确请求 AI 草稿，并重新生成报告以纳入该草稿；所有产物始终对应相同数据集和筛选条件。数据集或筛选变化后，先前摘要对当前视图失效。

### F01 — 上传 Excel/CSV [MUST]

- **业务目的：** 用明确的数据接收流程替代人工文件合并。
- **用户故事：** 作为分析师，我希望提交完整批次，以便联合分析所有数据域。
- **输入：** 符合第 4 节的文件。
- **行为：** 选择文件并指定数据域，展示文件名、大小和检测到的数据域；执行格式及数量限制，不激活数据。
- **预期输出：** 暂存批次，或可据此处理的上传失败信息。
- **边界情况：** 数据域缺失/重复、文件损坏或受密码保护、编码错误、空文件、超限、混合格式、公式单元格。
- **验收标准：** AC1：等价 Excel 和 CSV 样例暂存相同数据域记录。AC2：不支持或不完整的输入均说明失败原因，并保留当前数据集。AC3：仅上传不会改变分析结果。

### F02 — 校验结构与数据 [MUST]

- **业务目的：** 防止错误源数据形成看似可信的分析。
- **用户故事：** 作为分析师，我希望获得精确诊断，以便修正源文件。
- **输入：** 暂存批次和已记录的结构/关联规则。
- **行为：** 检查结构、缺失/无效值、唯一键、取值范围、跨域覆盖和产品一致性；收集可操作诊断，不静默丢弃行。
- **预期输出：** 通过/失败状态、受影响位置、规则 ID、原因和数量。
- **边界情况：** 空白与零、相同重复行、不合格品超过产量、非有限数值、键不匹配、不支持的额外字段。
- **验收标准：** AC1：每条规则的预设样例产生预期失败，有效样例通过。AC2：阻断性失败阻止该批次持久化及新 KPI/报告生成。AC3：能定位时指出源行/字段，结构错误指出文件/数据域。

### F03 — 规范化与转换 [MUST]

- **业务目的：** 统一允许的格式差异，不改变运营含义。
- **用户故事：** 作为分析师，我希望规范化透明可查，以便解释报告数据。
- **输入：** 可执行已记录转换的暂存值。
- **行为：** 去除文本首尾空白，统一允许的日期和数字表示，保留标识符，以一对一关系关联生产数据域，并重新校验转换后的值。格式校验仅认可这些允许的转换。
- **预期输出：** 标准化数据域记录，以及包含原始值和规范化值的操作日志。
- **边界情况：** 前导零标识符、含糊日期、小数计数、本地化小数字符串、去空白后产生重复键。
- **验收标准：** AC1：允许的等价表示得到相同规范值。AC2：含糊或改变含义的转换失败，不猜测。AC3：规范化后的键冲突阻断导入，转换保留源引用。

### F04 — 持久化规范化数据 [MUST]

- **业务目的：** 跨会话保留有效数据，防止部分更新。
- **用户故事：** 作为分析师，我希望已接受的数据在重启后保留，以免重复上传。
- **输入：** 完整校验后的规范化批次及来源元数据。
- **行为：** 原子提交四个数据域，仅成功后切换当前快照；等价重复导入不变更数据。写入失败保留原当前结果。
- **预期输出：** 持久的当前数据集、批次标识和导入结果。
- **边界情况：** 写入中断、存储不可用、重复批次、修订后的完整批次、没有历史数据时重启。
- **验收标准：** AC1：重启恢复已接受记录及元数据。AC2：模拟提交失败时旧数据完整保留，没有部分激活的数据域。AC3：等价重导不增加行数；修订批次替换而不是追加。

### F05 — 计算 KPI [MUST]

- **业务目的：** 提供一致、可核查的制造指标。
- **用户故事：** 作为经理，我希望 KPI 定义明确，以便可靠地比较运营表现。
- **输入：** 当前规范化数据集及适用筛选条件。
- **行为：** 在未来 KPI_DEFINITIONS 建立后，计算 K01–K07 所引用的获批指标，返回覆盖情况及比率的分子/分母依据。
- **预期输出：** 各视图和导出共享的可复用指标结果。
- **边界情况：** 分母为零、空筛选、加权汇总、超目标产量、陈旧/缺失库存快照。
- **验收标准：** AC1：与独立样例的计数完全一致，百分比误差不超过 0.01 个百分点。AC2：分母为零或筛选为空时适当展示 N/A。AC3：每物料仅使用一条符合条件的快照，不累加每日余额或不兼容单位。

### F06 — 检测规则异常 [MUST]

- **业务目的：** 将注意力引向需要调查的具体偏差。
- **用户故事：** 作为主管，我希望异常有证据支持，以便知道应检查哪些记录。
- **输入：** 有效所选记录、计算值及对应候选 R01–R04 的已批准、带版本规则；数值阈值尚未定义。
- **行为：** 在规定粒度应用固定比较并保留依据；区分跳过检查与检查通过。
- **预期输出：** 筛选后的异常列表、规则—记录数量及跳过评估数量。
- **边界情况：** 恰好等于阈值、一行触发多条规则、比率未定义、沿用历史库存、无异常。
- **验收标准：** AC1：各规则低于/等于/高于边界样例均产生准确预期结果。AC2：每条结果均有规则及来源依据。AC3：相同输入和设置产生相同结果，N/A 不得视为正常结果。

### F07 — Overview（总览）[MUST]

- **业务目的：** 为经理提供工厂数据的简明概览。
- **用户故事：** 作为经理，我希望有总览，以便定位需要关注的领域。
- **输入：** 共享 KPI/异常结果、校验状态、批次元数据、日期/产线/班次筛选。
- **行为：** 展示 K01–K05、K07、每日产量趋势、异常数量、数据覆盖和其他四个区域的导航。注明库存按日期计算，不受产线/班次筛选影响。
- **预期输出：** 应用内的一个汇总区域。
- **边界情况：** 无当前数据、筛选为空、最新导入失败但旧数据仍有效、无合适库存快照。
- **验收标准：** AC1：卡片和趋势与 F05 所选结果一致。AC2：筛选和批次标识可见，避免混淆分析对象。AC3：无数据状态及库存范围明确。

### F08 — Production（生产）[MUST]

- **业务目的：** 解释计划与实际产量以及停机差异。
- **用户故事：** 作为生产主管，我希望查看趋势和产线对比，以便发现未达目标的情况。
- **输入：** 关联后的生产记录及共享日期/产线/班次筛选。
- **行为：** 展示计划与实际产量、K01–K03、K05、每日趋势、产线对比和相关 R01/R03 记录明细。
- **预期输出：** 生产分析及支持行/源引用。
- **边界情况：** 计划为零、产量为零、达成率超过 100%、单产线、无所选记录。
- **验收标准：** AC1：图表总量、明细与所选 KPI 一致。AC2：超过 100% 的达成率正常展示，不截断。AC3：未定义比率和空结果有标识，不静默置零。

### F09 — Quality（质量）[MUST]

- **业务目的：** 展示不合格品模式，不暗示原因。
- **用户故事：** 作为质量人员，我希望查看不合格品趋势与来源依据，以便调查受影响班次。
- **输入：** 关联后的质量/实绩记录及共享筛选。
- **行为：** 展示产量、不合格品与合格品数量、K04 每日趋势和产线对比，以及 R02 明细。
- **预期输出：** 质量分析和可追溯的受影响记录。
- **边界情况：** 零产量、无不合格品、每日产量不同、质量记录缺失在导入阶段拒绝。
- **验收标准：** AC1：质量总量与 Production、K02/K04 一致。AC2：汇总不合格品率使用汇总数量计算。AC3：零产量的比率为 N/A；正产量无不合格品时为 0%。

### F10 — Inventory（库存）[MUST]

- **业务目的：** 通过透明的快照覆盖情况识别低于最低库存的物料。
- **用户故事：** 作为库存人员，我希望查看截止日期库存，以便复核低库存物料。
- **输入：** 库存快照、共享日期范围、可选的区域内物料筛选。
- **行为：** 展示 K06 及单位、最低库存、快照日期、历史沿用状态、K07 和 R04；产线/班次筛选不起作用。物料筛选仅影响本区域，不静默应用于完整报告。
- **预期输出：** 各物料库存表、低库存数量和覆盖情况。
- **边界情况：** 无此前快照、旧快照、单位不一致在接收时拒绝、等于最低库存、跨日多条快照。
- **验收标准：** AC1：取截止日期之前或当日最新快照，不取未来快照。AC2：历史沿用和覆盖缺失可见；等于阈值不算低库存。AC3：改变产线/班次不影响库存；范围和物料筛选有标识。

### F11 — Reports & Insights（报告与洞察）/ Excel 导出 [MUST]

- **业务目的：** 无需人工组装表格即可生成可复用的管理报表。
- **用户故事：** 作为分析师，我希望导出 Excel，以便经理在应用外检查结果。
- **输入：** 当前批次、共享筛选、KPI/异常依据、元数据和当前摘要。
- **行为：** 在 Reports & Insights 中预览报告范围，生成固定 `.xlsx` 报告，包含 Overview、Production、Quality、Inventory、Anomalies、Data Quality、Summary 工作表。库存包含截至结束日期的全部物料，不受产线/班次或 Inventory 局部物料筛选影响。导出为报告数据，不将源内容作为可执行公式。
- **预期输出：** 可下载 Excel 报告，单位、日期、定义、来源和摘要类型一致。
- **边界情况：** 无当前数据、生产筛选为空但库存有覆盖、写文件失败、类似公式的文本、过期摘要。
- **验收标准：** AC1：导出值在展示精度下与共享结果完全一致。AC2：工作簿打开无需修复，不可信文本不会作为公式执行。AC3：无数据集时阻止导出；其他情况标识空数据域；导出失败可见且可重试。AC4：范围变化后不能导出过期摘要。

### F12 — PDF 报告 [MUST]

- **业务目的：** 提供适合分享的可读管理产物。
- **用户故事：** 作为经理，我希望得到 PDF，以便阅读版式稳定的结果报告。
- **输入：** 与 F11 相同的报告范围和结果。
- **行为：** 生成固定版式 PDF，包含范围/覆盖、KPI 定义与数值、生产/质量趋势、库存概览、异常概览和管理摘要。按日期/规则/键稳定排序，包含前 20 条异常明细并标明截断；Excel 包含完整列表。
- **预期输出：** 可下载 PDF，图表和表格可读，包含页码、批次标识及生成时间。
- **边界情况：** 长标识符、大量异常、无异常、不可用值、导出失败、跨页表格。
- **验收标准：** AC1：PDF 与 Excel 的事实和筛选一致。AC2：对长内容、空数据、完整数据代表样例进行视觉检查，无文字裁切、重叠或不可读图表。AC3：截断明确披露，失败不改变应用数据。

### F13 — 可选 AI 管理摘要 [COULD 建议；发布优先级待 D07]

- **业务目的：** 展示基于已校验结果更快准备文字摘要的能力。
- **用户故事：** 作为经理，我希望获得可选 AI 草稿，以便复核并调整简明管理摘要。
- **输入：** 明确的生成请求，以及当前报告范围内受限的汇总事实、规则依据和局限；一个可选模型供应商。
- **行为：** 生成观察、局限和调查问题。标记 AI 生成及需人工复核。不计算 KPI，不将推测原因写成事实，不发送原始行。始终提供确定性模板摘要；缺凭据、超时、失败或响应不可用时回退。草稿绑定批次/筛选/规则版本，变化后失效。
- **预期输出：** 有标识的草稿或回退摘要，可纳入重新生成的 Excel/PDF 报告。
- **边界情况：** 无数据、无异常、N/A、供应商不可用、无依据的数值陈述、筛选变化。
- **验收标准：** AC1：核心流程离线完成。AC2：至少五个固定评估场景中，每项数值陈述与提供事实一致，不可用指标保持不可用；无依据的解释不表述为事实。AC3：模拟 API 故障返回回退摘要，不丢失报告/数据。AC4：范围变化使草稿失效，生成需用户明确操作。

## 7. 非强制功能规格

### S01 — 可下载输入指南 [SHOULD]

- **业务目的 / 用户故事：** 作为分析师，我希望有示例，以便减少准备有效输入时的试错。
- **输入：** 带版本的结构定义、干净/无效合成样例。
- **行为 / 输出：** 提供四域 Excel 模板、等价 CSV 示例及字段/规则字典下载。
- **边界情况：** 示例结构版本过期、样例文件缺失。
- **验收标准：** AC1：干净样例通过 F02；故意无效样例产生已记录错误。AC2：产物注明结构版本和合成来源。

### S02 — 基础可访问性 [SHOULD]

- **业务目的 / 用户故事：** 作为用户，我希望控件可读且可通过键盘操作，以便可靠浏览分析。
- **输入：** 五个区域、控件、图表和校验消息。
- **行为 / 输出：** 提供有标签的控件、可见键盘焦点、文字状态和图表对应表格。
- **边界情况：** 仅用颜色表示异常、长诊断文字、空图表。
- **验收标准：** AC1：上传、筛选、导航和导出可通过键盘操作。AC2：不依赖颜色即可理解状态，各图表数值可用文本/表格检查。

### C01 — 上期对比 [COULD]

- **业务目的 / 用户故事：** 作为经理，我希望与上期对比，以便理解当前生产表现的背景。
- **输入：** 当前日期范围，以及当前数据集中紧邻其前的等长范围，产线/班次筛选相同。
- **行为 / 输出：** 对比 K01–K05，展示绝对变化及比率的百分点变化。不增加库存对比。
- **边界情况：** 日期缺失、上期为空、比率未定义。
- **验收标准：** AC1：与独立计算的对比样例一致。AC2：展示覆盖缺失，无效对比为 N/A，不暗示改善。

## 9. 歧义与建议决策

D01–D11 及 D14–D15 仍为开放建议；D12 记录用户明确的双语文档要求，D13 记录已完成的 V0 创建。开放事项不授权实施，解决后记录批准及所属文档。

| ID | 歧义 | 建议决策及影响 |
| --- | --- | --- |
| D01 | 四域在一个文件还是分别上传？ | 每批一个四工作表 Excel 或四个指定数据域 CSV，不支持部分域导入。 |
| D02 | 产品、班次和时间粒度？ | 每日期/产线/班次一个产品；单工厂、单一本地日历，不处理日内时间或时区转换。混合产品班次需后续修订规范。 |
| D03 | 计划/实绩/质量覆盖可不同吗？ | 要求键一致及明确零记录，避免不完整比率偏差，但需要准备源数据。 |
| D04 | 库存具体含义？ | 带最低库存的截止日期快照，不含出入库、估值或生产核对。历史沿用日期可见。 |
| D05 | 增量导入、修正、历史？ | 整批替换当前快照，等价重复导入不变更，原子持久化并跨重启保留。无合并/历史界面，存储选型留待设计。 |
| D06 | 哪些异常及阈值？ | 考虑简单 R01–R04 观察，但在明确记录前不选择数值默认值。建议 KPI_DEFINITIONS 负责规则语义；确认归属、阈值、比较符、粒度及跳过/计数行为。无规则编辑器。 |
| D07 | 可选 AI 的发布承诺？ | 最新要求明确 AI 可选，撤回此前未获批的 MUST 能力解释。发布优先级达成一致前，将 F13 保留为 COULD 建议。核心分析/报告从不依赖 AI；独立于供应商交付，建议提供确定性摘要。 |
| D08 | 筛选如何影响库存和报告？ | 生产/质量共享日期/产线/班次；库存截至结束日期，不受产线/班次影响。库存局部物料筛选不影响完整报告，范围预览说明。 |
| D09 | 是否保留原 HTML 导出？ | 以 PDF 替代，保留两种格式。保留 HTML 需要额外范围决策。 |
| D10 | 输入限制和地区格式？ | 总计 10 MB / 10,000 行；严格 ISO/Excel 日期、UTF-8 CSV、固定结构、生产离散单位，不自动推断地区格式或单位。 |
| D11 | 扩展后的工作量和范围？ | 重新估算扩展后的 MUST 基线。增加复杂度前先删 COULD、延后 SHOULD，不假设原估算仍适用。 |
| D12 | 双语输出意味着什么？ | 用户已明确要求中英文文档对，记录为文档要求。应用/报告语言仍单独决策。 |

| D14 | 性能验收边界？ | 对齐章程端到端耗时与此前 PRD 分段目标；在质量文档记录约定负载、硬件及测量方法。 |
| D15 | 报告明细和版式限制？ | 七张 Excel 工作表及 PDF 20 条异常预览为旧草案建议，非获批限制。在 UI_SPEC/ACCEPTANCE_CRITERIA 解决版式、截断及范围披露。 |

## 10. 范围审查

保留要求的数据域和应用区域；仅快照分析为需 D04 解决的建议，不是实施指令。排除库存交易录入、多产品时间分摊、任意文件映射、增量核对、动态仪表板、异常配置和额外报告格式。五个区域是共享数据上的导航，不是五套独立应用。用户要求可靠持久化；原子快照替换是 D05 建议，不是存储架构决策。AGENTS V0 仍排除分布式基础设施。

剩余最大不确定性是数据域完整性、库存语义和扩展后的工时估算。实施前解决相关开放决策、对齐章程、建立缺失的权威文档，并审阅 AGENTS V1。本文提出有限的行为要求，不授权也不包含实现。
