## 工程结果（2026-09-17）

- 已起草配对的[验收标准](../../quality/ACCEPTANCE_CRITERIA.zh-CN.md)，含十项可测工程检查、八项明确的业务批准关口及章程–PRD 差异表。**客户验收仍待决**；产品负责人尚未批准候选制造业务口径或范围协调。
- 仓库配置及双语启动命令均将 Streamlit 绑定回环地址。本地进程仅监听 `127.0.0.1:8765`，`/_stcore/health` 返回 HTTP 200；验证进程随后关闭。
- 完整活跃批次读取现独立加载每个规范数据表，在筛选分析前拒绝生产键或来源引用不一致及存储内容指纹不匹配；孤儿记录与篡改探针已纳入回归测试。
- AI 响应只能选择白名单事实 ID；程序提供指标标签、数值及强制局限说明。自由文本虚假指标、设备原因及订单完工断言会触发回退。
- openpyxl 之前限制 XLSX 解压量、条目数和非空单元格数，工作表以只读流式读取；覆盖稀疏、密集及高压缩样例。
- PDF 筛选 ID 分置有长度上限且可分页的表格行。500 个 ID 的 PDF 测试通过；短 ID 分组后，长筛选报告从 18 页降为 5 页。已目视检查第 1、3、5 页的筛选项、KPI 表、图表及结尾章节清晰可读。任一报告格式失败时另一格式仍可取得。

最终验证：Python 3.12.2；`.venv/bin/ruff check .` **通过**；最终 PDF 分页优化前 `.venv/bin/pytest -v` **135 项通过，用时 38.38 秒**，优化后 `.venv/bin/pytest -q` **135 项通过，用时 45.17 秒**。未更改制造 KPI 公式、异常阈值或产品功能。
