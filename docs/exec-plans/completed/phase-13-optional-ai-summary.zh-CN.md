# 第 13 阶段——可选 AI 管理摘要

状态：已完成。英文对应：[phase-13-optional-ai-summary.md](phase-13-optional-ai-summary.md)。

在“Reports & Insights”中加入显式、按需触发的摘要操作。应用服务复用同一份已验证的报表结果，只投影已计算 KPI 的显示值和状态、有上限的异常证据、已准备好的每日趋势、筛选范围，以及批次和定义标识。提供方不接收原始记录，也不能访问数据库。可选 OpenAI Responses HTTP 适配器使用环境变量、有限超时和输出上限，关闭响应存储，不增加依赖。选择该提供方是本次明确要求的可选功能的实现假设；调用接口仍可替换。

禁用、缺少密钥、超时、API 失败或响应格式错误时，均从同一事实返回带原因标识的确定性摘要。拒绝结构错误和缺乏依据的数字陈述。AI 草稿仅临时保存，批次、筛选范围或规则变化后失效。提示人工复核；报表导出不会触发 AI。

仅使用模拟提供方和传输响应验证，并运行完整 pytest 与 Ruff。测试不调用真实 API。记录最终证据后将双语计划移至 completed。

## 完成证据与限制

- “Reports & Insights”现在通过应用服务按需生成摘要。AI 草稿带人工复核标识；其余情况返回带明确回退状态的确定性离线摘要。批次、筛选范围或异常阈值变化时清除页面缓存。报表导出仍独立于 AI。
- OpenAI Responses 适配器只发送有上限的事实投影，设置 `store=false`、12 秒超时及 650 token 输出上限。环境变量为 `MOI_AI_ENABLED`、`MOI_AI_API_KEY` 和 `MOI_AI_MODEL`；密钥不保存在设置对象、报表或 UI 状态中。项目不会自动加载 `.env`。
- 拒绝结构错误的响应及输入事实中没有依据的数字。此类机械校验不能证明因果或定性叙述正确，管理人员仍须复核 AI 草稿。本次未发出真实 API 请求，因此提供方账户可用性与在线模型表现尚未验证。
- `.venv/bin/pytest -q`：**124 个测试通过，耗时 34.93 秒**。`.venv/bin/ruff check .`：**全部通过**。新增 15 个测试使用模拟调用对象和 HTTP 响应，覆盖禁用、缺密钥、超时/失败、格式错误、无依据数字、身份不匹配、输入边界以及离线 UI 生成。
- 最后收紧校验，要求 AI 草稿必须包含限制说明；随后 `.venv/bin/pytest tests/test_management_summary.py -q` 的 **15 个测试通过**，Ruff 再次通过。
