# ADR-003 — 可选 AI 仅消费已计算结果

实施更新（2026-09-17）：后续用户明确任务已授权可选摘要。现有一个 OpenAI Responses 适配器及确定性回退实现此边界，未新增依赖。下文原始决策记录的是架构设计任务当时状态，不代表当前实施状态。参见[第 13 阶段](../exec-plans/completed/phase-13-optional-ai-summary.zh-CN.md)。

QA 加固（2026-09-17）：模型现在只能返回白名单内 KPI、异常或每日趋势事实的 ID。应用代码确定性地渲染数值和标签，并始终附上固定的局限说明。自由文本及不支持的 ID 会触发回退；不再以数字字符串匹配充当事实依据。AI 协助范围因此收窄为事实选择和排序。

日期：2026-09-15  
状态：可选性及结构化结果边界由用户要求；适配器设计为建议，供应商及发布承诺仍开放。  
英文对应文档：[ADR-003-ai-boundary.md](ADR-003-ai-boundary.md)

## 背景

项目应展示可选管理摘要，同时确保确定性分析和 Excel/PDF 报告离线可用。AGENTS V0 禁止 AI 定义制造规则、计算权威 KPI、修改原始数据或判定合规。PRD D07 保留可选功能发布优先级，架构不能将其变成核心依赖。

## 决策

本次不实现 AI 集成。保留一个小型可选摘要适配器，仅由应用服务在用户明确请求时调用。接收现有有效分析结果经白名单选取的结构化内容，不接收原始表格、完整记录表、SQL 访问或仓库句柄。

包含相关计算事实、单位、结果/事实标识、范围、批准对比、异常依据摘要及局限。领域仍是唯一计算负责方。UI 和报告渲染不直接调用供应商，导入和分析也不自动调用摘要适配器。

未来交付 AI 时，一个供应商可调用对象足够。现在不选供应商/模型/SDK。秘密通过环境变量及仅占位符的 `.env.example` 配置；启动核心应用不需要初始化可选供应商。新增重大依赖仍需批准。请求/输出设置有限边界，返回标记结果，不向外抛出未处理的供应商异常。

确定性摘要使用给定结果字段和预写管理语言，不计算新指标。AI 关闭、缺凭据、超时、网络错误或响应不可用时，返回回退文本或明确的叙述不可用状态。任何情况核心指标及报告下载仍可用。

每份草稿带来源数据集、实际范围及定义身份；任一变化则失效。明确生成后，导出可附加匹配摘要，导出本身从不触发 AI。不得静默将旧叙述附到新数值。

核对响应结构及数值陈述是否由结构化事实支持，拒绝无依据陈述。不宣称字符串/数值检查证明因果或叙述真实。仍需人工复核，并标识 AI 文本。AI 可提出调查优先级或问题，但没有执行操作、修改数据或判定工程/监管合规的工具权限。

## 考虑的替代方案

| 替代方案 | 处理 |
| --- | --- |
| LLM 从上传行计算 KPI | 拒绝：权威计算不确定，且不必要暴露原始数据。 |
| 报告生成强制 AI | 拒绝：将联网、成本及凭据加入核心路径。 |
| 自主智能体 / 数据库工具 | 拒绝：没有授权动作需求，且明确超出范围。 |
| 多供应商策略框架 | 不选：单个小型可选适配器足够。 |
| 仅确定性文本 | 合法核心/离线模式；不虚称可选 AI 已交付。 |

## 影响与限制

核心测试和演示无需 API 凭据或供应商专用包。有限边界隔离网络故障，支持测试中使用假供应商。不能保证 LLM 叙述正确，仍需复核事实依据和明确标识。

日常日志不包含提示词、完整模型载荷或秘密。按 AGENTS 使用合成数据。明确集成范围后记录供应商成本/超时/输出限制及响应格式。本 ADR 不批准聊天、检索、智能体或模型训练。

## 验证与重新审阅条件

在供应商不可用时验证核心 F01–F12；通过假可调用对象测试关闭/缺密钥/故障/格式错误/无依据陈述，以及过期身份失效。后续真实模型评估使用批准事实和已记录场景，不从模型输出建立业务规则。

仅在明确批准显著不同的 AI 能力或数据暴露后重新审阅，核心确定性边界必须保留。见 [架构第 10 节](../../ARCHITECTURE.zh-CN.md#10-可选-ai-边界) 和 [AGENTS V0](../../AGENTS.zh-CN.md)。
